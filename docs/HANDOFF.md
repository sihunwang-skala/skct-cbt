# 작업 인수인계 (다른 에이전트/사람이 이어서 작업할 때)

## 목표
SKCT 온라인 인지검사 응시 화면을 최대한 재현하는 개인용 CBT. 최우선은 **화면 재현도**. 그다음 문제은행 → 학습 분석.

## 현재 상태 (Phase 1~2 일부)
- 1920×1080 고정 스테이지 비례 스케일(`src/components/Stage.tsx`), 상단 빨간 바+남은 시간+시간 바.
- 시험 엔진: `src/engine/session.ts`(순수 함수, now 인자) / 계산기 `calc.ts` / 학습 기록 `coach.ts`.
- 영역별 도구: `src/data/profiles.ts`의 `tools`. 언어이해만 도구 없음(문제 전체 폭), 나머지는 메모장·그림판 탭(오른쪽 위)+계산기(오른쪽 아래).
- 쉬는 시간 60초. 이전 문항 복귀는 미확인이라 설정(기본 불가).
- 문제 15문항(자체 제작). 정답은 `src/data/questions.test.ts`에서 독립 검증.
- 테스트: `npm test`(25), `npm run e2e`(9, 스크린샷 `e2e/shots`).

## 확인된 사실 vs 미확인
- 확인(공식 안내서): 영역당 20문항 15분, 권장 1920×1080, 전체화면, 심층검사는 이전 문항 이동 불가.
- 사용자 기억: 전체화면, 글자 크기 중간, 문제가 화면 상단부터 시작해 보기까지 화면의 절반 조금 넘게 차지, 쉬는 시간 1분, 언어이해만 계산기 없음.
- 미확인: 계산기 키 배열/연산 순서, 메모·그림판 세부, 이전 문항 복귀 규칙, 감점 여부. 임의로 확정하지 말 것.

## 규칙
- 문제는 반드시 독립 검증(스크립트/브루트포스) 통과 후 `verification: 'script'`로 등록. LLM 자기검토만으로 정답 확정 금지.
- 실전모드에서 정답·해설 비노출.
- 저작권: 시판 교재/e-book/실제 기출을 공개 저장소에 커밋 금지. 개인 자료는 `private/`(gitignore).
- 다음 작업: 문제은행 확장(영역당 20+), 노션/이미지 Import(사용자 검토 UI), 유형별 훈련, 오답 재훈련.
